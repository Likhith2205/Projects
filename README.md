# Projects

A personal portfolio for showcasing selected projects, with concise write-ups on what I built, how it works, and the decisions behind it.

## Selected projects

Project write-ups will be added here as they are ready.

## Add a project

1. Copy the [project write-up template](docs/project-template.md) to `projects/<project-name>/README.md`.
2. Fill it in with the problem, your contribution, key decisions, and how you verified the result.
3. Add a link under **Selected projects** and verify that the write-up's links and run instructions work.
